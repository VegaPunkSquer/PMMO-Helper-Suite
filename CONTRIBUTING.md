# Contributing to The Silph Scope

First off, thank you for considering contributing to this project! It's people like you who make the gaming community better.

To maintain a high standard of code and ensure the tool remains stable, please follow these guidelines.

## 🐛 How to Report Bugs
If you find a bug, please open a GitHub **Issue** and include:
* A clear and descriptive title.
* Steps to reproduce the bug.
* Expected vs. actual behavior.
* Screenshots (if applicable).

## ✨ Feature Requests
Have an idea to make the tool better? Awesome! Please open an **Issue** first to discuss the feature before starting to code. This ensures the new feature aligns with the project's goals.

## 💻 Development Standards
To keep the codebase clean and maintainable, please follow these rules:
* **Language:** All code, comments, and documentation must be in English.
* **Style:** Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/) for Python code.
* **Variables:** Use meaningful, descriptive variable names (e.g., `calculate_hp_stat` instead of `calc_hp`).
* **Transparency:** Never include code that interacts with the game's memory, network traffic, or local game files. We are a 100% external companion app.

## 🚀 Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear messages.
4. Push to the branch.
5. Open a **Pull Request** describing your changes in detail.

Thank you for helping us build the ultimate tactical advantage!
